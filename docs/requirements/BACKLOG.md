# BACKLOG — Requerimientos e Historias de Usuario

## Historias de Usuario — Fase 1 (Sistema Interno & PDV WPC Bajío)

### US-COMM-007: Notificación por Correo y Comprobante PDF con Código de Barras para Abonos (Pendiente Fase 2)
- **Como** Cajero o Cliente,
- **Quiero** que al registrar un abono a una venta de apartado se genere automáticamente un archivo PDF del recibo con un Código de Barras escaneable del Folio/Recibo y se envíe una notificación por correo electrónico con los detalles del pedido y saldo pendiente al correo registrado del cliente,
- **Para** permitir que el cliente liquide su pedido o realice el siguiente abono de forma rápida escaneando directamente el código de barras en el mostrador.
